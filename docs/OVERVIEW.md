# Overview

`minimal-secure-app` is a React web application built with Vite and TypeScript.

## Status

Early scaffold stage. The app currently consists of the default Vite starter page; no product features have been implemented yet.

## Tech Stack

- React 19 + TypeScript
- Vite (build tool / dev server)
- Vitest + Testing Library (unit tests)
- ESLint + oxlint (linting)

See [`CLAUDE.md`](../CLAUDE.md) for commands and architecture notes.
